# Smart-Route-Planner-Using-Djikstra-s-Algorithm-In-C
A C++ console application that models a road network (undirected weighted graph) and computes the shortest path between a source and destination while forcing traversal through user-specified intermediate nodes. Uses Dijkstra’s algorithm to calculate segment distances and prints the full route and total distance. Ideal for learning graph algorithms, pathfinding with constraints, and interactive CLI design.

Features:

Add roads (edges) with arbitrary weights

Find shortest path that must pass through custom intermediate nodes

Displays segment-by-segment route and total distance

Simple menu-driven interface
